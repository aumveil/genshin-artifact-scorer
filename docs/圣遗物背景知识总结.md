# 圣遗物背景知识总结

## 一、圣遗物概述

圣遗物是《原神》游戏中的一种装备，用于角色养成。

- 每个角色装备 **5 个部位**：生之花、死之羽、时之沙、空之杯、理之冠（简称 花 / 羽 / 沙 / 杯 / 头）。

## 二、属性体系

每件圣遗物包含 **1 条主属性 + 4 条副属性**（5★）。

### 2.1 主属性（每件仅 1 条）

| 部位     | 主属性规则    |
| ------ | -------- |
| 花（生之花） | 固定为数值生命值 |
| 羽（死之羽） | 固定为数值攻击力 |
| 沙（时之沙） | 随机       |
| 杯（空之杯） | 随机       |
| 头（理之冠） | 随机       |

主属性共 **18 种**：生命值、攻击力、生命值百分比、攻击力百分比、防御力百分比、元素精通、元素充能效率、暴击率、暴击伤害、治疗、物伤、风伤、岩伤、雷伤、草伤、水伤、火伤、冰伤。

### 2.2 副属性

副属性共 **10 种**：生命值、攻击力、防御力、生命值百分比、攻击力百分比、防御力百分比、元素精通、元素充能效率、暴击率、暴击伤害。

### 2.3 不重复原则

同一件圣遗物的主、副属性不会出现完全相同的词条。  
例如：花的主属性为数值生命值，则其副词条不能再出数值生命值，但可以出生命值百分比。

## 三、强化机制

### 3.1 等级与副词条解锁

- 圣遗物等级上限为 **20 级**。
- 强化到 **4 / 8 / 12 / 16 / 20 级** 各获得一次副词条机会，共 **5 次**。
- **5★ 圣遗物初始固定为 4 条副属性**（其中最多 1 条未激活，需强化到 4 级解锁）。
- 当副属性已满 4 条后，后续强化会在已有词条中随机抽取一条进行**叠加**。

### 3.2 强化档位（单发数值档位）

- 每条副属性每次 roll 从 **4 个档位**中随机取一档，档位间比例关系为 **7 : 8 : 9 : 10**（第 4 档为最大值）。
- 一件 5★ 圣遗物的某条副词条最多经历「初始 1 次 + 强化 5 次」共 **6 次 roll**，该词条的显示值 = 各次 roll 之和。
- 「滚数当量」= 该词条显示值 ÷ 对应词条的满挡单发最大值（Umax），用于评估词条质量。

## 四、副词条数值表

每条副词条每次强化从 4 个档位中随机取值，第 4 档即满挡单发最大值（Umax）：

| ------ | ----- | ----- | ----- | ----------------- |

## 五、有效属性

- 不同角色需要的主属性和副属性各不相同。
- **被需要的属性称为「有效属性」**。

## 六、圣遗物重塑

### 6.1 系统概述

- 圣遗物重塑是 **5.7 版本（2025-06）实装的常驻养成系统**：消耗道具「**启圣之尘**」，重新分配满级圣遗物的强化落点。
- 定位：解决「胚子组合好、强化分配歪」的问题——**词条组合无法改变，但强化落点可以重来**，大幅缩短毕业周期。
- 关联道具「**祝圣之霜**」：自定义圣遗物（自选主词条与 2 条副词条，生成一件新的满级圣遗物）。经其定义的圣遗物在重塑时，定义时选的 2 条副词条**自动作为重塑指定词条**，无需再选。

### 6.2 重塑规则

| 规则 | 内容 |
| ------ | ------ |
| 适用对象 | 仅 **5★ 满级（20 级）** 圣遗物 |
| 不变项 | 4 条副词条的**种类与初始数值均不变** |
| 重掷项 | 全部强化落点**重新随机分配** |
| 词条指定 | 重塑前须**指定 2 条期望词条**；重塑时该 2 条词条的合计命中次数享受保底 |
| 保底档位 | 基础档 ≥**2** 次 / 高阶档 ≥**3** 次 / 谕告档 ≥**4** 次（2 条词条**共享**保底计数） |
| 结果选择 | 重塑后可预览新分配，自选「**维持原状**」或「**采用结果**」；已消耗的启圣之尘不返还 |

### 6.3 圣言解明（保底进度）

- 每消耗 **1 枚启圣之尘 +1 点**进度；进度满 **6 点**时，当次重塑消耗 6 点触发「**高阶重塑**」（保底命中 3 次）。
- 每触发 **2 次**高阶重塑后，下一次高阶改为「**谕告重塑**」（保底命中 4 次）——即每 **18 枚尘**一个谕告周期。
- 进度为**账号级共享**：不同圣遗物的重塑共同积累，已积累的进度/保底可继承给其他圣遗物（花羽攒的进度可用于杯头）。

### 6.4 消耗规则

| 部位 | 单次消耗 |
| ------ | ------ |
| 生之花、死之羽 | 1 枚 |
| 时之沙、空之杯、理之冠 | 2 枚 |

- 圣言解明进度**按尘数积累**（沙/杯/头一次重塑 +2 点）→ 各部位触发保底所需**总尘数相同**：高阶 6 枚、谕告 18 枚。

### 6.5 获取途径

- **幽境危战**（5.7 起的常驻挑战，每版本）：免费至多 **3 枚**——单人通关险恶Ⅳ、无畏Ⅴ各 1 枚 + 每版本累计消耗 1200 体力领取「危战嘉奖」1 枚。
- **珍珠纪行 / 珍珠之歌**（付费）：各 1 枚/版本。
- 版本更新邮件等临时赠送。
- 免费速率约 3 枚/版本 → 攒满一个谕告周期（18 枚）约需半年。

### 6.6 与本项目的关联

- 重塑的数学建模（安全网分布、期望与保底、价值分 RV）见《圣遗物评分算法设计.md》第五章「**算法四：圣遗物重塑价值评估**」。
- **可重掷强化次数 n**：4 初始 = 5、3 初始 = 4（3 初始件第 1 次强化用于生成第 4 词条，该词条及其数值在重塑中不变）。
- **强化档位期望**：四档等概率 → 单次 roll 期望 = 0.85 × 满挡值（即算法四的 ROLL_AVG = 0.85，见 3.2 档位比例 7 : 8 : 9 : 10）。
- **口径衔接**：游戏实际中初始副词条有 **3 条与 4 条两种形态**（3 初始件的第 4 词条在首次强化时随机生成）；本文 3.1 统一表述为「初始 4 条（最多 1 条未激活）」，其中「未激活」条目对应 3 初始形态——本项目将其属性和数值交由用户录入确定（见《圣遗物评分算法设计.md》1.1 录入约定）。

## 附：与其他资料的一致性说明

本文档以《圣遗物评分标准.md》为准：**5★ 圣遗物初始固定 4 条副属性**（最多 1 条未激活，强化到 4 级解锁），副属性满 4 条后强化进行随机叠加。

《圣遗物散件计算.md》中提到的「初始三：可强化 4 次；初始四：可强化 5 次」与上述口径不同。经确认，本项目统一采用评分标准的规则（初始 4 条、其中最多 1 条未激活）；3 初始（3 条激活 + 1 条待激活）已由《圣遗物评分算法设计.md》通过 `activated` 字段支持（待激活词条 4 级解锁后生效，属性和数值由用户录入确定）。
